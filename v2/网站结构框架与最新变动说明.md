## 一、整体信息架构与四段空间流向

### 1. 顶部导航顺序与默认落地页
- **导航顺序（`.header-nav`）**：`Intro` (`#about`) → `作品` (`#collection`) → `探索` (`#explore`) → `联系` (`#contact`)
- **默认首屏落地**：`作品`（`works`，`scrollY = 0`，`body` 无 `data-section` 属性）。
- **全局持久容器**（所有主视图与详情视图共享）：
  - `.site-header`（品牌 `simo® / PORTFOLIO.CAS` + 静音开关 `.sound-toggle` + 4 项带 Airbnb 风格微图标的主导航）
  - `.archive-player`（底部播放控制条与作品目录抽屉 `#archive-player-queue`，通过 `MutationObserver` 监听 `body[data-section]` / `data-layout` 与 `#story-dialog[open]` 实时同步进度与状态）
  - `#section-damping-cue`（越界阻尼提示胶囊，平时挂载于 `document.body`，当 `#story-dialog` 打开时自动迁入 `#story-dialog` 顶层以确保可见）

### 2. 四段垂直流向与边界阻尼（`SECTION_FLOW`）
页面按 `['about', 'works', 'explore', 'contact']` 建立连续垂直动线：
1. **`Intro` (`#about`)**：3 台悬挂式 3D MP3 播放器展示区。每次进入时触发 `Mp3AboutCluster.entranceSwing()` 从顶部垂落入场；支持拖拽碰撞、180° 翻转背面、播放/暂停；点击中间钴蓝 MP3 屏幕触发 `window.SimoOpenPersonalPaper()` 直达展开态个人折页 `#experience`。
2. **`作品` (`#collection` + `#project-index` + `#about-foldout`)**：
   - 保留完整内容结构：4 盘 3D 项目卡带（`磁带架` / `作品目录` 两种视图切换）+ 底部紧接 5 折个人档案折页 `#about-foldout`（`#paper-shelf`）。
   - **首屏顶部继续下拉（上拉越界）** → 阻尼蓄力后进入 `Intro`。
   - **页尾折页全部展开后继续下滑** → 阻尼蓄力后进入 `探索`。
3. **`探索` (`#explore`)**：3 张可 360° 拖拽与套壳/裸盘切换的 3D CD 盒（`全部 / 分享 / 工具` 筛选）。页顶上滑返回 `作品` 底部，页底继续下滑进入 `联系`。
4. **`联系` (`#contact`)**：以作者个人定位为核心的联系占位页（姓名/别名、职位与年限、在任角色、个人简介、4 项核心能力标签、邮箱及一键复制、电话、完整简历 PDF、`展开个人折页 ↗`）。页顶上滑返回 `探索`。

### 3. 详情弹窗（`#story-dialog`）内部上下衔接
- 当打开任一卡带项目（`project1` ~ `project4`）或探索 CD 详情（`talk-player-style` ~ `tool-creative-kit`）时：
  - 在当前详情页**顶部继续下拉** → 阻尼蓄力后切换至**上一篇详情**（首篇顶不再上跳）。
  - 在当前详情页**底部继续下滑** → 阻尼蓄力后切换至**下一篇详情**（末篇底不再下跳）。
  - 详情池按类别隔离：卡带详情仅在 4 个项目之间流动（`DETAIL_PROJECTS` 不含个人折页 `about`）；探索详情仅在 3 个探索条目之间流动（`explorations`）。

## 三、状态与路由契约（子类目接入必读）

1. **`body` 状态属性**：
   - `body[data-section]`：取值 `'about'` | `'explore'` | `'contact'`；**未设置时即为默认 `works` 视图**。
   - `body[data-layout]`：仅在 `works` 下生效，取值 `'shelf'`（磁带架，默认）或 `'index'`（作品目录）。
   - `body.story-open`：详情弹窗 `#story-dialog` 打开时添加。
   - `body.has-page-scroll`：`window.scrollY > 8` 时添加，控制顶部渐隐背景蒙层。
2. **URL Hash 与 History 映射**：
   - `#about` → `Intro`（MP3 页）
   - `#explore` → `探索`（CD 架）
   - `#contact` → `联系`（个人定位与联系页）
   - `#experience` → `作品` 底部已完全展开的个人折页（如从 MP3 蓝屏或联系页跳转而来）
   - `#<projectId>` / `#<exploreId>` → 直接打开对应项目或探索详情弹窗
3. **全局桥接 API**：
   - `window.SimoSectionFlow.current()` / `.step(dir)`：获取当前主板块或触发跨板块切换。
   - `window.SimoOpenPersonalPaper()`：从任何板块跳转并直接展开 `#experience` 个人折页。
   - `window.ArchivePaperBreeze.diagnostics()`：读取折页彩蛋触发状态与微风/提拉参数。
   - `window.Mp3AboutCluster`：控制 `Intro` 页 3D MP3 实例（进入 `about` 自动 `entranceSwing()`，离开自动 `stop()` 节省性能）。

## 四、近期关键变动全量汇总（2026-11-17 ~ 2026-11-18）

### 1. 交互流向与导航结构重构（`b3ddb36` 及本轮迭代）
- **导航重排与更名**：主导航从旧序改为 `Intro` → `作品` → `探索` → `联系`，默认首屏落在 `作品`。
- **越界阻尼换页系统**：
  - 支持主视图四段互切（`Intro ⇄ 作品 ⇄ 探索 ⇄ 联系`）以及 `#story-dialog` 详情页内部相邻条目上下边界切换。
  - **位移安全隔离**：`getSectionShiftTargets()` 只对非 `fixed` / `sticky` 内部内容容器施加阻尼位移（`#about .about-stage-only`、`#collection .tape-stage`、`#paper-shelf`、`#project-index`、`#explore .cd-showcase`、`#contact .contact-sheet`、`#story-content`、`.story-object-inner`），避免把 `#main-content` 或 `#story-dialog` 变成 containing block 导致顶部固定栏或吸顶控件跳闪。
  - **高阻力阈值与节奏**：桌面端 `WHEEL_THRESHOLD = 420`、单事件步进上限 `48`、`WHEEL_HOLD_MS = 640`、边缘防惯性结算 `BOUNDARY_SETTLE_MS = 280`；移动端 `TOUCH_THRESHOLD = 148`，支持贴近底部后单指继续上拉无缝衔接阻尼。
- **阻尼胶囊视觉与物理动效升级**：
  - 图标统一替换为与折页提示一致的拟物鼠标图标（`.damping-cue-mouse`），鼠标滚轮随拉动方向与进度同步位移。
  - **慢慢绷紧 → 阈值爆发**：跟随 `--damping-progress`（`Math.pow(clamped, 1.15)`）渐进收紧胶囊缩放（`scale(0.955, 0.93)`）、增强边框/阴影与进度条厚度；达到阈值时进入 115ms `is-bursting` 爆发状态（胶囊回弹外扩 + 外圈光环 `::after` 脉冲消散），随后完成切换。

### 2. 个人折页点击行为与彩蛋触发改版
- **保留 `作品` 原有内容**：继续保持 4 盘卡带 + 底部 5 折个人档案。
- **修复点击直达展开**：修正 `openItem('about', trigger)` 的触发源判断，将 `#paper-shelf`、`.now-playing` 与 `#rack` / `#shelf-index` / `.archive-player` 统一映射为 `revealAbout(false)`（在当前页平滑展开五折折页，不再误跳转到 MP3 页面）。从 `Intro` 的钴蓝 MP3 屏幕点击 `SimoOpenPersonalPaper()` 时直接定位至展开态 `#experience`。
- **彩蛋触发重做（`sound-effects.js`）**：
  - 因底部继续下滑已让位给进入 `探索`，移除原有基于底部滚动过冲（`wheel`/`touchmove` overscroll）的彩蛋触发，**保留正常滚动展开折页逻辑不变**。
  - 当五折折页完全展开（`progress >= 0.985`）后，支持在纸张**下半部**（避开邮箱/电话等 `<a>` 链接）通过：
    - **移动端**：手指按住下半部 `>= 240ms` 自动轻掀纸角并触发微震动与纸张沙沙声，显露 `有幸，彩蛋被你找到了🎊`，松手回弹；
    - **桌面端**：鼠标在下半部点按并向上拖拽拉起，随上拉幅度掀开底折显露彩蛋，松手回弹。

### 3. 联系占位页与 Explore / Intro 集成
- **联系页 `#contact`**：以作者个人定位作为占位内容主体（`徐晓强 / Simo`、`UX Design Lead · 11 年经验 · 网易云音乐 平台基础线设计负责人`、核心特质描述、4 项能力标签），并整合邮箱复制按钮、电话、简历 PDF 与折页入口。
- **Explore 与 Intro 集成（`6bd373b`）**：接入 3 张可 360° 翻转的探索 CD 盒与实机视频叠加演示，以及 `Intro` 页 3 台 3D MP3 垂落与后台自动休眠渲染。
